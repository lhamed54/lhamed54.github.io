Questions

Before you buy

Do I need to know how to code?

No. Claude writes all the code. You type requests in plain English. The playbook covers the one-time setup step by step, including the few terminal commands you'll need.

What do I need to run it?

A Mac, Windows or Linux computer with Node.js, and Claude Code, which needs a paid Claude plan (Pro or higher) or Anthropic API credits. For voiceovers, an ElevenLabs account.

Does it do voiceovers?

Yes. The kit voices your script with ElevenLabs and syncs the captions to every word. You need your own ElevenLabs account, and the free plan is enough to try it. The playbook walks you through setup. You can also make captions-only reels with no account at all.

Is Remotion free?

Remotion is free for individuals and companies of up to three people. Larger companies need a company licence from remotion.dev.

Will my reels look like everyone else's?

No. Claude writes new animation code for every reel, so the same topic comes out differently each time. Mix styles and your own ideas to make the page yours.
